# Agent Instructions

These instructions apply to AI agents working in this repository. Read CONTRIBUTING.md before making changes; it defines the development standards and contribution workflow.

- Check the active branch and working tree before editing. Preserve existing user changes and follow any more specific AGENTS.md instructions in affected directories.
- Keep changes within the requested scope. Reuse existing widgets, themes, styles, services, and helpers when appropriate.
- Do not introduce unrelated files, directories, dependencies, tools, or platform targets. Android and iOS are the only supported platforms.
- Keep source identifiers, comments, and documentation in English. Follow the product's language and existing localization approach for user-facing text.
- Protect secrets, signing material, local configuration, caches, and build output. Keep pubspec.lock tracked.
- Do not create branches, commit, push, open or merge pull requests, or delete branches unless the user explicitly requests that action.
- Run checks appropriate to the change and report only checks actually performed. Do not add test infrastructure or dependencies unless the task requires them.
